# UI / Animation — Kruthic ✨🎨

## Ownership & Domain
**Owner**: Kruthic (UI, Animation & Visual Experience Lead)

This directory houses the visual assets, design tokens, styling systems, and animation pipelines that make ARCANA-AI feel immersive, cohesive, and premium.

## Strict Boundaries
### UI / Animation OWNS:
- Design token definitions (colors, typography, spacing, shadows, borders).
- Component visual styling (Tailwind themes, CSS Modules, or Godot themes).
- Micro-interactions, hover states, and smooth transitions.
- Lottie animations, vector illustrations, and particle effect assets.
- Visual feedback cues (correct/incorrect answer effects, level-up particles, boss shield pulses).
- Design system documentation and asset management.

### UI / Animation DOES NOT OWN:
- Frontend application state management or network requests (owned by Jeenth).
- Game physics or gameplay mechanics (owned by Dasarth).
- Educational content or difficulty scaling (owned by Adarsh).

## Asset Delivery Structure
```
ui-animation-kruthic/
├── tokens/           # Color palettes, typography, spacing JSON specs
├── animations/       # Lottie JSONs, keyframe definitions, sprite animations
├── components/       # Reusable styled UI component primitives
├── sounds/           # UI feedback audio cues (clicks, success, warning)
└── guidelines/       # Design system documentation & style guides
```
